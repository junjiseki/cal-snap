# プランナー枠 証書（無料・有料）

本書は、カロリースナップにおける **無料プラン（free）** および **有料プラン（paid）** の利用枠を、実装・運用上の根拠とともに定義する。サポート・表記揺れ防止・法令表記（特商法ページ等）との整合確認に用いる。

**根拠となるアプリ内の識別子:** `profiles.plan` の値 `free` | `paid`（真実のソースは Stripe 連携後も本フィールドを参照する。詳細は `docs/stripe-spec.md`）。

---

## 無料枠 証書

**証する。** 無料プラン利用者には、次の枠が付与される。

| 項目 | 内容 |
|------|------|
| **AI 食事写真解析** | 1 ユーザーあたり **1 日あたり**、**成功した解析**を **上限回数まで**利用できる。上限の既定値は **1 回/日**。当日の区間は日本標準時（`Asia/Tokyo`）の暦日 0:00〜23:59:59.999 に相当する範囲でカウントする。 |
| **手入力による食事登録** | AI 解析枠の消費なしで、数値の手入力により食事を登録できる（本証書では回数上限を別途設けない）。 |
| **ダッシュボード・記録閲覧** | 登録済みの食事・カロリー・PFC・目標カロリーに基づく表示を利用できる。無料プランでは **当日** のダッシュボード中心表示に制限がある（過去日の閲覧は有料プラン向けの実装に従う）。 |
| **食事メニュー提案（AI）** | **付与しない**（有料プラン限定）。 |
| **食事画像の永続保存** | **行わない**（解析処理に必要な範囲で一時的に扱い、長期保存の対象としない）。有料・無料を問わず同方針。 |

**環境変数による上書き:** `FREE_DAILY_ANALYSIS_LIMIT` が正の整数として設定されている場合、AI 解析の 1 日上限はその値に置き換えられる（未設定・不正値時はコード上の既定値）。実装: `lib/meal-analysis.ts` の `FREE_DAILY_ANALYSIS_LIMIT`。

---

## 有料枠 証書

**証する。** 有料プラン利用者には、無料枠の内容に加え、次の枠が付与される。

| 項目 | 内容 |
|------|------|
| **AI 食事写真解析** | 1 ユーザーあたり **1 日あたり**、**成功した解析**を **上限回数まで**利用できる。上限の既定値は **3 回/日**。カウントの暦日・タイムゾーンは無料枠と同じ。 |
| **食事メニュー提案（AI）** | **1 日あたり** **上限回数まで**利用できる。上限の既定値は **3 回/日**（`MEAL_SUGGESTION_DAILY_LIMIT`）。 |
| **ダッシュボード** | 実装上、**過去日の選択表示** 等、無料プランより広い閲覧が可能な場合がある（詳細は `app/dashboard/page.tsx` 等の分岐）。 |
| **料金** | 販売条件・価格・支払・解約は **特定商取引法に基づく表記**（例: `app/commerce-disclosure/page.tsx`）および Stripe の利用規約に従う。本証書単体で価格を拘束しない。 |
| **食事画像の永続保存** | 無料枠と同様 **行わない**。 |

**環境変数による上書き:** `PAID_DAILY_ANALYSIS_LIMIT` が正の整数として設定されている場合、有料側の AI 解析 1 日上限はその値に置き換えられる。実装: `lib/meal-analysis.ts` の `PAID_DAILY_ANALYSIS_LIMIT`。
